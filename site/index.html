A programming language project

A language of its own.

Shay is an independent hybrid programming language with original syntax, a dedicated interpreter, and a native compiler toolchain. It is built in the open and evolving one feature at a time.

Explore the source code → Start using Shay → Read the documentation →

About Shay

Shay is designed around its own vocabulary and file formats, with an interpreter and a native compiler in the same toolchain. The project focuses on making a distinct language while steadily improving its implementation, diagnostics, and developer experience.

Getting started

Clone the repository and build the project with the included Makefile. Check the README for platform-specific notes and the latest build instructions.

git clone https://github.com/theprojectcreatorof2amthoughts/Shay.git
cd Shay
make
make test

Writing Shay

Shay uses its own keywords for declarations, output, functions, and control flow. Here is a small example:

## A first Shay program
brew name = "world"
instxt-"Hello, "
insval-name

brew score = 42
ifit score >= 40
instxt-"You did it!"
exec

For the complete and current syntax, use the syntax reference in the repository.

The toolchain

shaii — interpreter

Run Shay source files directly and check source syntax from the command line.

gshai — native compiler

Compile supported Shay programs into native executables or relocatable .sho object files.

Libraries and task files

Shay's ecosystem includes .shaii libraries and .shaz task files.
