01 / The idea

A language, not just a syntax theme.

Shay has its own vocabulary and file formats, backed by a shared lexer and parser. The project is developed as an evolving language and toolchain.

INTERPRET

shaii

Run Shay source files directly and check source syntax from the command line.

COMPILE

gshai

Compile supported Shay programs into native executables or relocatable .sho object files.

LIBRARIES

Shaii + Zeccurs

Use .shaii libraries and .shaz task files through Shay's import system.

02 / A taste of Shay

Readable by design. Distinct by choice.

Shay uses its own keywords for declarations, output, functions, and control flow.

## Variables and output
brew language = "Shay"
instxt-"Welcome to"
insval-language

## A function
$declr add(x, y)
    forw x + y
finish

insval-add(8, 4)
## Conditional logic
brew temperature = 24

ifit temperature >= 20 andit temperature < 30
    instxt-"Comfortable"
elseit
    instxt-"Check the weather"
exec

Examples show currently documented syntax. Language capabilities are evolving; see the syntax reference for implementation details.

03 / Get started

Build the tools. Run your first program.

Build requirements: a C11 compiler, a C++20 compiler, and GNU Make or CMake 3.20+.

Build

git clone https://github.com/theprojectcreatorof2amthoughts/Shay.git
cd Shay
make
make test

Run and compile

./build/shaii examples/hello.shay
./build/shaii --check examples/hello.shay
./build/gshai -o hello examples/hello.shay
./hello

See the repository README for installation, compiler flags, CMake, and object-file instructions.

05 / What's next

Built in the open. Growing step by step.

The roadmap is aspirational; these are areas of ongoing and future development, not promises that every feature is already available.

Language foundations

Richer expressions, robust diagnostics, expanded values, scopes, and control flow.

Developer experience

More standard-library modules, improved tooling, clearer errors, and a possible interactive REPL.

Native ecosystem

Compiler improvements, object linking, optimization, and a C/C++ interoperability story.
